# esp32-robot

Firmware del ESP32-S3 principal del robot de fútbol **auxi**: mando Xbox por
Bluetooth, tres sensores de distancia y UART con la ESP32-CAM.

## Compilar y subir

Requiere [PlatformIO](https://platformio.org/).

```
pio run -t upload
```
